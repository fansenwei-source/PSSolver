# S-09 D-0013 累计结案候选

本记录在不修改冻结分析器、阈值、案例或 192 项 profile 的前提下，对作业
`10911538` 的全部持久化数据执行不中断重算。16 个分组中，只有
`channel_legacy` 和 `channel_compiled_v2` 的 `channel_R512x40x40`、float32
分组在 `peak_reserved` 一项失败；二者均为
`562036736 / 545259520 = 1.0307692307692307`。同一分组的
`peak_allocated=1.0150638559607594`，六个 trial 和全部计时统计均通过；其余
14 个分组全部通过。

用户确认的 `D-0013` 只接受上述两个观测为有界设计取舍，不改变 `1.03` 参考值，
也不能推广到其他 family、grid、dtype、runtime 或未来版本。诊断作业 `10912583`
与 `R-0031` 的 CUDA allocator snapshot 证明：accepted A·p 持久缓存一直保留到
`compute_nonlinear` 的分配峰值，增量为一个压力场。精确撤回代理虽然恢复显存，
但 R128 总均值计时超过冻结参考；数值终态逐位相同。

因此 V-41 按 `D-0013` 改为 `accepted`；V-42 按 `R-0031` 改为 `verified`。
