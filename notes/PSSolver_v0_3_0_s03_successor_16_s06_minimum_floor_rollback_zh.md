# PSSolver v0.3 S-06 最小递推残差回滚候选

日期：2026-10-22

本候选针对 R-0015 的两项小范围返工要求：固定迭代压力求解达到数值下限后，保存的回滚候选从
“最后一个不高于下限的状态”改为“递推残差最小且不高于下限的状态”；只有真正回滚时，返回状态
才必须通过严格的一倍下限真实残差复算。未发生回滚的正常完成保持 S-06 前的接受语义，并限制在
两倍下限以内；使用该余量前仍优先尝试满足严格后条件的已存候选。

运行时实现提交是 `f6da20f71ed2b7ae63ab07b19103eb6c29a95829`。生产、functional transpose、
implicit primal 与 unrolled oracle 四条路径采用同一规则，公开精度下限、checkpoint schema、
provider identity 和生产默认值均未改变。

Claude 指定的原始脚本结果：2160 次压力扫描中 `fail_closed=0`，没有真实残差高于下限的可接受
结果；360 次首个下限交叉扫描中 `fail_closed=0`，最大接受值为下限的
`1.0053485113310139` 倍。压力扫描摘要明确记录了失败关闭总数。本地完整资格归档将在 R-0016
请求前绑定到机器可读记录。

登记表中的 C1-05、C2-18、S2-17、V-27、V-28、V-29 均保持 `claimed_fixed`，等待 R-0016
独立复核，不提前标为 verified。本轮没有 push、HPCC、Slurm、GPU 或 H100 操作。
