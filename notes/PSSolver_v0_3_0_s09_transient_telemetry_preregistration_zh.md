# S-09 单次瞬态遥测预登记

本记录冻结 `Q-S09-PERF-03 = A` 的一次性分析测量。它只分析先前
`Channel functional / relative_tolerance` 的 CPU 瞬态，不替代正式 H100
资格合同，也不放宽 1.03 / 1.05 门限。

测量固定到 CPU 8；六个配对试验各保留 60 个样本并交替顺序。逐步记录
wall time、进程 CPU time、上下文切换、缺页、CPU 频率和系统负载。测量前
主机 24 个逻辑 CPU 的两秒平均空闲率为 99.79%，没有 Python、pytest 或
Control 研究计算；仅存在 Claude 的低负载日志监视器，因此没有暂停进程。

若超限配对同时满足预登记的进程 CPU、缺页、上下文切换/失调度时间或频率
事件之一，则归类为环境干扰；只有冻结八单元格中位比和 focused 中位比都
不超过 1.03 时，CPU 预检才可作为参考性估计继续。若证据支持候选自己的
预热/首次调用开销，或原因仍无法裁决，则必须先停止定位。所有旧失败、全部
样本和旧判定原样保留。

正式 H100 仍使用 1.03 / 1.05、保留全部样本；提交草稿必须先交 Claude，且
H100 仍需用户另行授权。
