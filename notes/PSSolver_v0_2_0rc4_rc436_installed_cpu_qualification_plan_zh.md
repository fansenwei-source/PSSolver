# PSSolver RC4.3.6 installed-wheel lifting CPU 资格计划

RC4.3.6 从精确 Git commit 的 clean archive 构建 wheel，并在源码目录之外的新 venv 中以 `--no-deps` 安装。runner 必须正面证明 `pssolver` 来自该 venv 的 purelib、`sys.path` 不含源码 checkout、`pip check` 通过，并以原子 JSON 保存 11 项 installed-wheel 结果。

这 11 项同时在 source checkout 中运行，覆盖公开 lifted Plane 的稳定 fail-closed 边界、受支持 homogeneous-Neumann Plane 的 requested/effective 语义、field-neutral lifting pipeline 的独立二阶 manufactured diffusion、localized quintic fresh-only 调理，以及内部 lifted Plane 的同版本文件 checkpoint 逐字节恢复。独立收敛只资格化 field-neutral lifting pipeline，不得被解释为重新开放 RC4.3.3 已关闭的 public lifted Beris–Edwards 组合。

本阶段不修改 runtime 热路径、checkpoint 接受规则、PSSolver-Control、`nematics3d` 或生产默认值，也不运行 H100。通过 installed-wheel 门禁后仍需运行完整 source CPU suite；RC4.3.7 的 CUDA/H100 正确性、性能和显存资格需要用户另行明确授权。
